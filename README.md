Descripción del Proyecto
Este proyecto es un ejercicio de revisión integral de lógica y algoritmos. Su objetivo principal es calcular la edad exacta de una persona en años, comparando el año de nacimiento con la fecha actual del sistema.

Incluye un **Filtro de Consistencia** para validar que las fechas ingresadas existan en el calendario real (días válidos por mes y verificación de años bisiestos).
